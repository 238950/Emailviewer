# 学生邮件查看器（Student Mail Viewer）

本地运行、中文界面、只读的学生邮件查看器：聚合你的邮件、自动分类与摘要、识别截止时间并加入内置日历、统一管理附件、深色模式。**不含写信/回复功能。**

界面地址固定为 **http://127.0.0.1:3869**（本机回环地址，**3869 即服务端口**，不对局域网/公网开放）。

数据来源支持两种（见下），**推荐「IMAP 云端直连」模式（也是默认方式）**：用自己的邮箱「应用密码 / 授权码」直连云端 IMAP，任何邮箱都适用，并且能与新版 Outlook 并行使用（已读/未读都作用于云端同一封邮件，状态互通）。

**「经典 Outlook 桌面」是替代方案**：仅在你本机装有**经典 Outlook（classic）并已登录该账号**时可用；它走 COM/PowerShell 自动化读取本地已同步邮件，**无需邮箱密码**，但受本地缓存范围限制。

> ⚠️ **新版 Outlook（`1.2026.x`，WebView2 架构）没有 COM 自动化接口**，无法作为本查看器的本地数据源被读取。用新版 Outlook 的同学请选 **IMAP 云端直连**。

> 详细操作请看 **[使用指南.md](使用指南.md)**；每个文件的用途与二次开发请看 **[开发指南.md](开发指南.md)**。

## 一、快速开始

1. 本机需安装 Node.js ≥ 22（可到 https://nodejs.org 下载）。
2. 双击 **`EmailViewer.exe`**（无参数）：首次会自动安装依赖（可见进度），随后**服务后台无窗口启动**并自动打开 **http://127.0.0.1:3869**。
3. 点右上 **「添加账户」**（向导默认就是推荐项）：
   - **IMAP 云端直连（推荐 / 默认）**：选邮箱服务商 → 填邮箱地址 → 粘贴「应用密码/授权码」→ 测试连接 → 保存并同步；任何邮箱都适用，**新版 Outlook 用户也选这项**；
   - 或 **经典 Outlook 桌面**（替代方案）：仅本机装有**经典 Outlook（classic）且已登录该账号**时可用，检测本机账号 → 选择 → 保存并同步，**无需邮箱密码**。
4. 其它动作同一个 EXE 完成：`EmailViewer.exe silent`（仅后台静默启动，供开机自启）/ `stop`（停止服务，即结束占用 **3869** 端口的进程）/ `debug`（带可见控制台窗口启动，用于排错）/ `status`（弹窗显示运行状态与地址）；**开机自启默认开启**（Run → `EmailViewer.exe silent`），可在「设置 → 启动与通知」关闭。启动器日志为 `launcher.log`，服务日志为 `server\data\server.log`。
5. 邮件与缓存保存在 `server\data`（可随时删除重新来过，属“空白”状态）。

## 二、功能一览

| 功能 | 说明 |
|---|---|
| **首页（5 列智能整理）** | 推荐活动 / 重要邮件 / 临近截止 / 未读速览 / **低相关邮件**；**每封邮件只归属一列**（不重复）；卡片可一键「已阅」归档并从首页隐藏，左下角「**重要已阅**」可找回或取消 |
| 多账户统一视图 | 主账户展开文件夹树，副账户折叠为“圆点+未读数”；「智能收件箱」跨账户汇总 |
| 同步 | 自动定时 + 手动刷新 + 实时未读数（IMAP / 经典 Outlook 桌面双数据源）；本地缓存即时出列表 |
| **AI 助手（Chatbox）** | 自然语言操作邮箱：**直接读取压缩后的邮件内容**作答；读取范围可选「仅附带邮件 / 自动检索相关 / 最近未读」；未配置 AI 时自动降级为本地检索 |
| **单封邮件送 AI** | 阅读窗格顶部**渐变高亮按钮「让 AI 读这封邮件」**→ 带着该邮件跳到对话页并自动提问，方便针对性追问 |
| **日历智能化** | AI 分类时同时提取 deadline/考试/活动时间；日历页「**从邮件智能安排**」一键批量建事件（自动去重、限量）；阅读窗格支持「全部加入日历」 |
| 邮件通知 | 同步发现新邮件 → 系统通知 + 提醒中心条目，点击直接打开最新邮件（可关闭） |
| 开机自启 / 单 EXE | 启动、静默启动、调试、停止、状态全部由 `EmailViewer.exe` 一个文件提供（无参数 / `silent` / `debug` / `stop` / `status`），**不再需要任何批处理或脚本启动器**；设置内可开关自启 |
| 邮件查看 | HTML/纯文本渲染、远程图片拦截、附件预览/下载、完整邮件头；阅读窗格窄屏自动变抽屉 |
| 搜索过滤 | 主题/发件人/收件人/正文/日期/附件类型；高级过滤规则自动打标/归类/加星 |
| 智能分类与价值评分 | 课程/作业/成绩/社团/系统/营销/垃圾/个人 + 0-3 价值分（AI 或本地规则），驱动首页排序 |
| AI 配置 | OpenAI 兼容通用适配：内置预设 + 自定义服务商（可增删）+ 一键拉取模型列表；密钥仅本机加密保存、界面只显示前4后4 |
| 摘要 | 列表正文摘要；长邮件一句话摘要（AI，无 Key 走关键词法） |
| 日历提醒 | 自动识别邮件中的“下周一 23:59 / 12月20日前”等日期，一键加入内置日历；每日未读重点汇总 |
| 附件管理 | 按类型/“杂项水印”分组、可按时间或大小排序、预览（图片/PDF/文本）、一键存本地、内容哈希去重（同内容只缓存一份） |
| 体验 | 中文界面、深色/浅色/跟随系统、草稿箱默认隐藏（设置可开） |

## 五、安全与隐私

- 服务仅监听 `127.0.0.1`，不对局域网/公网开放。
- IMAP 密码（应用密码 / 授权码）使用本地 AES 加密存储（密钥在 `server\data\secret.key`）；**经典 Outlook 桌面模式不保存任何邮箱密码**（凭据由本机 Outlook 自己管理）。
- 邮件正文与附件仅保存在本机 `server\data`；远程图片默认拦截，防止被追踪。
- 停止使用：运行 `EmailViewer.exe stop`（即结束占用 **3869** 端口的服务进程）即可；彻底删除数据：删除 `server\data`。

## 六、已知边界

- 仅实现 IMAP 协议；POP3 因缺少文件夹/未读语义未支持（**经典 Outlook 桌面模式**可覆盖 POP 邮箱场景）。
- **新版 Outlook（`1.2026.x`，WebView2 架构）没有 COM 自动化接口**，不能被本查看器直接读取；它对应的邮箱请改用 **IMAP 云端直连** 同步。经典 Outlook 桌面模式还额外要求本机已安装并登录 classic Outlook，且只能看到其本地缓存范围内的邮件。
- Office 附件提供下载，未做网页内联转换预览。
- 日历为内置日历，不做 Google/Outlook 实时双向同步，支持导出 .ics。
- 首轮同步默认回看 30 天（设置中可调整）。
